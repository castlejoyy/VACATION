# 여행 계획표 (VACATION)

핸드폰에서도 바로 표를 탭해서 수정할 수 있는 여행 일정표 웹앱입니다.
서버 없이 GitHub Pages로 바로 배포할 수 있고, 접속 암호를 아는 특정 사람들끼리만
링크로 공유해서 실시간으로 같이 수정할 수 있습니다.

## 폴더 구조

```
vacation-planner/
├── index.html            메인 페이지
├── css/style.css          디자인
├── js/app.js              전체 로직 (일정표, 숙소 정보, 저장/동기화)
├── js/firebase-config.js  Firebase 연결 설정값 (직접 채워야 함)
└── README.md              이 파일
```

## 기능 요약

- **일정표**: 왼쪽엔 30분 단위 시간(기본 04:00 ~ 다음날 02:00, ⚙️ 설정에서
  자유롭게 변경 가능, 예: 7시~22시), 위쪽엔 날짜+요일(예: `9/6(일)`)이 있는 표.
  원하는 칸을 탭하면 바로 글자를 입력할 수 있어요.
- **1안 / 2안 등 대안 계획**: 표 위의 탭으로 여러 계획을 전환하며 각각 따로
  입력할 수 있고, "＋ 대안 추가"로 3안, 4안도 계속 늘릴 수 있어요.
- **칸 합치기(셀 병합)**: 표 위의 "🔗 칸 합치기"를 누르면 병합 모드가 켜져요.
  합치고 싶은 칸을 몇 개든, 순서 상관없이 탭해서 선택(하이라이트)한 뒤
  "✅ 합치기"를 누르면 선택한 칸들을 아우르는 범위가 한 칸으로 합쳐져요.
  (2칸이든 5칸이든 원하는 만큼 가능해요) 이미 합쳐진 칸을 탭하면 그 자리에서
  바로 다시 낱개로 나뉘어요. (엑셀의 셀 병합과 같은 개념 — 여러 시간에 걸친
  활동을 한 칸으로 표시할 때 사용)
- **여러 여행 관리**: 상단의 여행 이름(또는 🗂️ 아이콘)을 누르면 지금까지 만든
  모든 여행 목록이 나와요. "＋ 새 여행 만들기"로 새 여행을 추가하고, 목록에서
  탭해서 여행을 전환하거나, ✏️로 이름을 바꾸거나, 🗑로 삭제할 수 있어요.
  같은 접속 암호를 쓰는 사람들은 이 여행 목록 전체를 함께 보고 관리해요.
- **숙소 정보**: 숙소 이름/위치/체크인·체크아웃 시간과, 부가시설(조식, 수영장 등)의
  이름/이용시간/세부내용을 여러 개 추가할 수 있어요. 각 부가시설 왼쪽의 ▲▼ 버튼으로
  순서도 바꿀 수 있어요. (여행별로 따로 저장돼요)
- **주변 정보**(📍 탭): 근처 식당/카페/가볼만한 곳을 이름·구분(식당/카페/가볼만한 곳/기타)·
  위치·영업시간·메모로 따로 정리할 수 있어요.
- **일정표 칸 ↔ 숙소/부가시설/주변정보 연결**: 일정표의 각 칸 오른쪽 위에 작은
  "＋" 배지가 있어요. 탭하면 등록해둔 숙소/부가시설/주변 정보 중 하나를 골라 그
  칸에 연결할 수 있고, 칸이 비어있었다면 그 항목 이름이 자동으로 채워져요.
  연결된 칸은 배지가 "🔗"로 바뀌고, 다시 탭하면 위치/시간/메모 같은 세부내용을
  일정표를 벗어나지 않고 바로 확인할 수 있어요("변경"으로 다른 항목으로 바꾸거나
  "연결 해제"도 가능). 숙소 정보·주변 정보 탭을 계속 왔다갔다 하지 않아도 되게
  만든 기능이에요.
- **여행 설정**(⚙️ 아이콘): 지금 보고 있는 여행의 이름, 시작 날짜(2026년 기준),
  여행 일수, 일정표 시작/종료 시각을 바꿀 수 있어요.
- **실시간 공유**: Firebase를 연결하면, 접속 암호를 아는 사람들끼리 링크로
  들어와서 동시에 수정한 내용(여행 목록, 각 여행의 일정표·숙소 정보 포함)이
  서로에게 실시간으로 반영돼요.

## 1단계. Firebase 무료 데이터베이스 만들기 (실시간 공유용)

이 단계를 건너뛰면 앱은 자동으로 "로컬 저장 모드"로 동작합니다. 즉 내 폰/PC
브라우저에만 저장되고, 다른 사람과는 공유되지 않아요. 여러 명이 같은 계획표를
실시간으로 같이 보고 수정하려면 아래를 진행하세요. (구글 계정만 있으면 무료입니다)

1. https://console.firebase.google.com 접속 → 로그인 → **프로젝트 추가**
2. 프로젝트 이름 입력(예: `vacation-planner`) → 애널리틱스는 꺼도 무방 → 프로젝트 생성
3. 왼쪽 메뉴 **빌드 > Realtime Database** → **데이터베이스 만들기**
   - 위치는 기본값 그대로 두어도 됩니다.
   - 보안 규칙은 우선 **테스트 모드**로 시작합니다.
4. 데이터베이스가 생성되면, **규칙(Rules)** 탭에서 아래 내용으로 바꾸고 게시하세요.
   (링크를 아는 사람만 자신들의 방(room)에만 접근할 수 있게 하는 최소한의 규칙입니다)

   ```json
   {
     "rules": {
       "trips": {
         "$roomId": {
           ".read": true,
           ".write": true
         }
       },
       "$other": {
         ".read": false,
         ".write": false
       }
     }
   }
   ```

   > ⚠️ 이건 정식 로그인 인증이 아니라 "암호를 해시로 변환한 값(방 번호)을 아는
   > 사람만 그 방에 접근 가능"한 방식이에요. 가족/친구끼리 캐주얼하게 공유하는
   > 용도로는 충분하지만, 민감한 개인정보는 넣지 않는 걸 추천해요.

5. 왼쪽 위 **⚙️ 프로젝트 설정 > 일반** 탭으로 이동 → 아래로 스크롤 →
   **내 앱**에서 **웹 아이콘(</>)** 클릭 → 앱 닉네임 입력 후 앱 등록
   (Firebase Hosting 체크는 안 해도 됩니다)
6. 화면에 나오는 `firebaseConfig` 객체 값을 복사해서, 이 프로젝트의
   `js/firebase-config.js` 파일 안의 값들을 그대로 바꿔치기 하세요.

   ```js
   window.FIREBASE_CONFIG = {
     apiKey: "...",
     authDomain: "...",
     databaseURL: "...",   // Realtime Database 탭에도 같은 주소가 나와요
     projectId: "...",
     storageBucket: "...",
     messagingSenderId: "...",
     appId: "..."
   };
   ```

   Firebase의 웹 API 키는 서버 비밀키가 아니라 "이 도메인/앱에서 왔다"는 걸
   식별하는 공개 식별자라서, 소스코드에 그대로 들어가도 괜찮습니다(실제 접근
   제어는 위 4번의 Realtime Database 규칙이 담당해요).

## 2단계. Cursor에서 GitHub(`VACATION` 저장소)에 연결하기

이미 GitHub에 `VACATION` 저장소를 만들어두셨다고 하셨으니, Cursor에서 이 폴더를
열고 아래 순서로 연결하면 됩니다.

1. Cursor에서 이 `vacation-planner` 폴더를 열기
2. 터미널(Cursor 안의 터미널 패널)에서:

   ```bash
   git init
   git add .
   git commit -m "여행 계획표 초기 버전"
   git branch -M main
   git remote add origin https://github.com/<본인계정>/VACATION.git
   git push -u origin main
   ```

   (Cursor의 소스 컨트롤 탭에서 GUI로 커밋/푸시해도 동일합니다)

3. GitHub 저장소 페이지 → **Settings > Pages** → Source를 **Deploy from a branch**,
   Branch를 **main / (root)** 로 설정 → Save
4. 잠시 후 `https://<본인계정>.github.io/VACATION/` 주소로 접속하면 앱이 열립니다.
   이 링크가 바로 "특정인에게만 공유할 링크"예요.

## 3단계. 접속 암호로 특정 사람에게만 공유하기

- 처음 링크에 들어가면 **암호 입력 화면**이 나옵니다.
- 나와 같이 여행 계획을 짤 사람들에게 **① 링크 + ② 암호**를 함께 알려주세요.
- 같은 암호를 입력한 사람들끼리는 같은 "방"(Firebase 경로)에 접속되어,
  누가 어디를 수정하든 서로의 화면에 실시간으로 반영됩니다.
- 자기 기기에서 한 번 암호를 입력하면 다음부터는 자동으로 다시 들어가지고,
  우측 상단 🔒 아이콘을 누르면 암호 입력 화면으로 다시 잠글 수 있어요.
- 암호를 바꾸고 싶으면 그냥 새 암호로 다시 입력하면 되는데, 이 경우 이전
  데이터와는 다른 새 "방"이 생성된다는 점 참고하세요.

## 로컬에서 미리 보기 (배포 전 테스트)

`index.html`을 그냥 더블클릭해서 열어도 대부분 동작하지만, 브라우저 보안 정책상
로컬 파일(`file://`)에서는 일부 기능이 제한될 수 있어요. 아래처럼 간단한 로컬
서버를 띄워서 보는 걸 추천합니다.

```bash
cd vacation-planner
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 자주 바꾸는 값

- 새 여행을 만들 때 기본 여행 이름/시작 날짜/일수/시간 범위: `js/app.js` 상단의
  `defaultTripData()` 함수 안 `meta` 값 (앱 안 ⚙️ 설정에서도 바로 바꿀 수 있어요)
- 시간표 30분 단위 간격 자체를 바꾸려면 `js/app.js`의 `getTimeSlots()` 함수 수정
- 디자인 색상: `css/style.css` 맨 위 `:root` 변수들
